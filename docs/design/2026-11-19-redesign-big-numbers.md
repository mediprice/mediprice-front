# 리디자인: "큰 숫자" (2026-11-19)

## 왜

사용자 평가: 지금 디자인은 흔해 보이고(파란 SaaS 템플릿), 정보가 한눈에 안 들어오고, 정적이다.

경쟁 서비스 조사(모두닥, 굿닥, 똑닥, 강남언니, 바비톡, 닥터나우, 케어닥, 심평원, 토스, 호갱노노)에서 고른 방향은 **A안 "큰 숫자"**다.

- 가격 숫자가 화면의 주인공이다.
- 결론을 먼저 말하는 문장형 제목을 쓴다.
- 최저–평균–최고 범위 막대가 모든 가격 화면에 나온다.
- 홈에는 절제된 인터랙션을 넣는다.

## 성공 기준

- 어느 가격 화면이든 첫 화면에서 "이 항목은 보통 얼마이고, 이 병원은 싼 편인지"가 3초 안에 읽힌다.
- 홈이 살아 있다: 숫자 롤업, 예시가 바뀌는 검색, 탭 전환, 스크롤 등장.
- 단, 멈춤 수단이 있고 `prefers-reduced-motion`이면 모두 정지 상태로 보인다.
- 고령 사용자 기준은 유지한다.
  - 본문 16px 이상(모바일 보조 글자 13px 이하는 최소화)
  - 터치 44px 이상
  - 텍스트 대비 4.5:1, 컨트롤 테두리 3:1
- 그라데이션, 왼쪽 선 강조, 이모지, 첫 방문 팝업, 멈출 수 없는 자동 슬라이드는 쓰지 않는다.
- 기존 기능, 라우트, API 연동, 테스트는 그대로 동작한다(`pnpm check` 통과).

## 1. 시각 언어 (토큰, `src/app/globals.css`)

토큰 **이름은 유지**하고 값만 바꾼다. 화면 코드 대부분은 그대로 새 룩을 받는다.

| 토큰                                   | 새 값                             | 메모                                               |
| -------------------------------------- | --------------------------------- | -------------------------------------------------- |
| `bg`                                   | `#ffffff`                         | 바탕은 흰색 하나                                   |
| `surface` / `surface-strong`           | `#f3f5f7` / `#e6eaee`             | 묶음 면 / 눌림·비활성                              |
| `text-primary` / `secondary`           | `#16202b` / `#4a5563`             | 16.5:1 / 7.6:1                                     |
| `text-tertiary` / `disabled`           | `#5e6976` / `#66717e`             | surface-strong 위에서도 4.5:1 / 4.1:1              |
| `border` / `border-strong`             | `#e3e7eb` / `#7d8894`             | 장식용 구분선 / 컨트롤 테두리(3:1 이상)            |
| `hairline`                             | `#eef1f4`                         | 목록 행 구분선                                     |
| `primary` / `-hover` / `-pressed`      | `#1a5fd8` / `#1753be` / `#1448a5` | 맑은 파랑, 흰 글자 5.7:1                           |
| `primary-text`                         | `#1a56c4`                         | 흰 바탕과 tint 위 링크·강조 글자                   |
| `primary-tint` / `-hover` / `-pressed` | `#ebf2fe` / `#dde9fd` / `#cedffc` | 선택 상태, 칩, 작은 강조 면에만 쓴다(넓은 띠 금지) |
| `positive` / `warning` / `danger`      | `#0b7a52` / `#9a5b00` / `#a82424` | 상태에는 항상 아이콘이나 글자를 같이 쓴다          |

- **넓은 색 띠는 쓰지 않는다.** 페이지 머리는 흰 바탕에 큰 제목만 둔다. 섹션 구분은 여백(`spacing-section`)과 `surface` 면으로 한다.
- **그림자**: `shadow-card`는 거의 보이지 않게 약하게 바꾼다. 묶음은 `surface` 면과 `rounded-2xl` 이상으로 표현한다. `float`·`sheet`·`bar`는 겹치는 요소에만 쓴다.
- **타이포**
  - 새 토큰 `text-price-hero`: 모바일 40/48, 데스크톱 56/64, 굵기 800, 자간 -0.02em.
  - `price-xl`·`price-lg`는 한 단계씩 키운다.
  - 모든 `price-*`에 `font-variant-numeric: tabular-nums`를 기본으로 넣는다.
  - 문장형 제목은 `hero`·`display`를 쓴다.
- **모서리**: 카드와 묶음 면은 `rounded-2xl`(20), 큰 면은 `rounded-3xl`, 버튼은 `rounded-xl`, 칩은 `rounded-full`.
- **움직임**: `ease-standard`, 200–400ms. 숫자 롤업 600–900ms. 스크롤 등장은 12px 아래에서 떠오르며 opacity가 바뀐다.

## 2. 공용 컴포넌트 (`src/components/ui`, 모두 테스트 가능한 순수 로직 분리)

- **`RangeBar`**
  - 최저–평균–최고를 가로 막대 하나에 그린다.
  - 선택 가격(이 병원 값) 표시를 옵션으로 둔다.
  - 마커 아래에 금액 라벨을 붙이고, 데이터가 부족하면 막대를 숨긴다.
  - 막대는 장식(`aria-hidden`)이다. 의미는 옆 텍스트와 `sr-only` 문장으로 전한다.
  - 위치 계산은 순수 함수 `rangePosition(min, max, value)`로 두고 테스트한다.
  - 처음 보일 때 왼쪽에서 오른쪽으로 그려진다(reduced-motion이면 바로 표시).
- **`RollingNumber`**
  - 숫자가 0에서 목표값으로 굴러 올라간다.
  - 화면에 처음 보일 때 한 번만 재생한다.
  - 접근성 이름은 최종값이고, 움직이는 숫자는 `aria-hidden`이다.
  - reduced-motion이면 정지 상태다.
- **`Reveal`**: `IntersectionObserver`로 스크롤 등장. 서버 렌더 시에는 보이는 상태로 시작해 JS가 없어도 내용이 보인다.
- **`useRotation(length, intervalMs)`**
  - 일정 간격으로 순서를 돌린다.
  - 다음과 같을 때 멈춘다: 마우스를 올렸을 때, 포커스가 들어왔을 때, 탭이 숨겨졌을 때, 사용자가 멈춤을 눌렀을 때, reduced-motion일 때.
  - 다음과 멈춤 버튼을 함께 제공한다.
- **기존 컴포넌트를 새 룩으로 조정**:
  - `Button`, `Chip`, `Tag`, `SegmentedControl`, `EmptyState`, `SectionHeader`
  - `PriceOverview`: 평균을 크게 쓰고 `RangeBar`를 포함한다.
  - `HospitalPriceGroupCard`: 행과 구분선 형태로, 가격은 오른쪽 큰 숫자로, 범위 막대 안에 이 병원의 위치를 표시한다.
  - 셸(`TopNav`, `MobileTopBar`, `BottomTabBar`, `SiteFooter`)

## 3. 홈 (`src/app/(shell)/(tabs)`)

위에서 아래 순서다.

1. **검색 히어로**
   - 문장형 제목("어떤 진료비가 궁금하세요?").
   - 큰 검색창의 예시 문구가 인기 항목 이름으로 바뀐다. 포커스되면 멈추고, 화면 낭독기에는 고정 문구가 나온다.
   - 아래에 인기 검색어 칩을 둔다.
   - AI 찾기 진입 링크.
2. **오늘의 가격 카드**
   - 인기 항목 하나를 큰 숫자로 보여 준다.
     - "도수치료, 서울·경기 평균"
     - `RollingNumber` 평균가
     - `RangeBar` 최저–최고
     - "병원 N곳"
   - 약 6초마다 다음 항목으로 넘어간다. 멈춤, 다음 버튼, 점 표시가 있다.
   - 카드를 누르면 항목 화면으로 간다.
   - 데이터는 `npayQueries.summaryIn`(지역 서울·경기)을 쓴다.
3. **많이 찾는 항목**
   - 지역 탭(서울·경기 / 서울 / 경기, `SegmentedControl`)을 둔다.
   - 행마다 순위, 항목명, 평균가, 미니 `RangeBar`, 병원 수를 보여 준다.
   - 탭을 바꾸면 숫자가 다시 롤업된다.
   - 순위는 `POPULAR_ITEMS` 순서다. 실제 인기 순위 API가 생기면 교체한다.
4. **분야별 찾기**: 큰 타일 그리드(아이콘 + 16px 이상 라벨), 누르면 눌림 반응.
5. **AI 찾기 미리보기**
   - 사용자 말풍선 "허리가 아프고 다리가 저려요"가 타이핑된 뒤 항목 칩(도수치료, MRI)이 나타난다.
   - 화면에 들어올 때 한 번만 재생하고, 누르면 `/ai`로 간다.
   - 데모임을 표시한다("이렇게 물어보면").
6. **이용 순서**: 3단계, 번호 + 짧은 문장, 스크롤 등장.
7. **믿을 수 있는 이유와 FAQ**: 출처(건강보험심사평가원)와 기준일, 짧은 FAQ 아코디언.

## 4. 다른 화면

새 토큰과 공용 컴포넌트를 쓰고, 화면마다 결론 문장과 범위 막대를 넣는다.

- **검색 `/search`**
  - 흰 머리, 큰 검색창.
  - 항목 결과 행에 평균가와 미니 `RangeBar`.
  - 분류 화면은 큰 타일.
- **항목 `/items/[code]`**
  - 머리를 "도수치료, 서울·경기 평균 **N원**"(`RollingNumber`)과 `RangeBar`로 만든다.
  - 병원 목록은 행과 구분선으로, 각 행 가격 옆에 "평균보다 N% 저렴/비쌈" 꼬리표를 둔다. 텍스트와 아이콘을 함께 쓰고, 기준은 같은 데이터의 평균이다.
- **병원 `/hospitals/[ykiho]`**
  - 머리는 흰 바탕에 큰 병원명을 둔다.
  - 선택 항목 가격은 `text-price-hero`로, 항목 평균 대비 위치를 `RangeBar`로 보여 준다.
  - 가격 목록은 행 형태다.
- **비교 `/compare`**
  - 가격 행마다 범위 막대 위에 비교 병원 위치를 점으로 찍는다.
  - 최저가 병원은 텍스트와 아이콘으로 강조한다.
- **지도 `/map`**: 마커와 목록 행을 새 룩으로.
- **AI `/ai`**: 말풍선, 결과 카드, 입력창을 새 룩으로. 결과 항목에 평균가와 미니 `RangeBar`를 넣는다.
- **내 정보와 하위 화면, 관심, 로그인 대화상자**: 흰 머리, 목록 행, 새 버튼과 칩.

## 5. 데이터 제약

- 전체 통계(병원 수, 항목 수)와 실제 인기 순위 API는 없다.
- 이번에는 항목별 `summaryIn`(평균, 최저, 최고, 병원 수)과 고정 `POPULAR_ITEMS`만 쓴다.
- 통계 API는 백엔드 후속 과제다.
- 홈 요청 수: 인기 항목 6개 × 지역 3개가 최대다. 탭을 처음 열 때만 요청하고 React Query 캐시를 쓴다.
